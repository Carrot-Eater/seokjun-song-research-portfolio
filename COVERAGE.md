## Excluded or not independently attributed

- **Course assignments**, including the CIFAR-10 assignment, are excluded at the author's request.
- **MiroFish-person-twin** was located as an upstream-based tree. A sufficiently specific original contribution was not established in this audit, so it is not presented as a standalone authored project.
- **pl_ws / Point-LIO**, upstream PX4, SLAM and MAPIR/GADEN trees are supporting dependencies, not independent inventions by this portfolio's author.
- Empty/unresolved project labels, including MYCLAUDE_PROJECT, are not turned into invented achievements.
- Backups, build/install trees, virtual environments, downloaded models, datasets, robot bags, repeated exports and generated deployment copies are not separate achievements.
- Raw participant material, accounts, private conversations, credentials, operational endpoints, unpublished manuscripts and private academic records are excluded from publication.

## How to interpret completeness

The current release contains 36 linked work-item summaries across eight fields. Four source modules are published with recorded provenance. All remaining cards are explicitly documentation releases. This is a broader catalog than the initial seven-row overview; it is still not a full source backup or a claim that every historical file has been attributed and validated.

For the portfolio counts, an item is a navigable unit of work. Several items share one parent project, dataset or research question. File counts, lines of code and candidate-manuscript counts are not used as measures of research achievement.
