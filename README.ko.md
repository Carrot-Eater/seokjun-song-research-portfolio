# 송석준 연구·개발 포트폴리오

[영문 홈](README.md) · [전체 작업 36개](ALL_WORK.md) · [기술 목록](TECHNOLOGY_MATRIX.md) · [조사 범위](COVERAGE.md)

컴퓨터에서 확인한 연구·개발 작업을 **8개 분야, 36개 세부 작업 항목**으로 정리했습니다. 수업 과제는 제외하고 PersonTwin 연구와 서비스·앱을 포함했습니다.

| Field / 분야 | Work items |
|---|---:|

| [Environmental sensing · 전자코·환경·청각 센싱](areas/environmental-sensing/README.md) | 6 |

| [Research applications · 태양광·마이닝 연구 기획](areas/applications/README.md) | 1 |

각 항목을 열면 작업 내용, 사용 기술, 확인한 근거, 현재 구현·검증 수준과 외부 프로젝트 활용 범위를 볼 수 있습니다. 연구실 검토를 고려해 상세 설명은 영문으로 작성했습니다.

**공개 범위:** 분야별 설명과 36개 작업 카드, 대표 소스 모듈 4개 및 관련 테스트가 공개되어 있습니다. 모든 프로젝트의 전체 원본 코드를 올린 상태는 아닙니다. 코드가 공개된 항목과 설명만 공개된 항목을 전체 목록에 구분했습니다.

**집계 기준:** 같은 프로젝트의 모듈·실험 주제를 찾기 쉽게 나눴습니다. 36편의 논문이나 독립적으로 완성된 프로젝트 36개라는 뜻이 아닙니다. 백업, 빌드 산출물, 같은 원고의 버전은 별도 성과로 세지 않았습니다.

로봇 실험, 시뮬레이션, 공개 데이터 분석, 서비스 프로토타입, 하드웨어 설계, 향후 연구 기획의 수준을 구분했습니다. 논문 초안은 게재 실적으로 표기하지 않았고, 태양광·마이닝은 응용 연구 계획으로 표시했습니다.

비밀키·운영 계정·참여자 기록·개인 대화·원시 데이터·미공개 원고는 공개하지 않습니다. 전체 디스크의 모든 파일을 빠짐없이 검증했다는 의미는 아니며, 확인한 프로젝트군과 제외·보류 범위는 [조사 범위](COVERAGE.md)에 남겼습니다.
