# Interview and retest collection protocol

인터뷰·재검사 수집 프로토콜

[Area index](../../areas/persontwin/README.md) · [All work](../../ALL_WORK.md) · [Claim boundaries](../../EVIDENCE.md)

**Status:** Protocol / collection software draft

**Catalog reviewed:** 12 October 2026

Make consent, question versions and repeated measurement explicit in a person-modelling study.

## Work represented

- Independently written life-history interview questions and a bounded interview budget.
- Separation of US instruments, Korean translations and Korean adaptations.
- Collection-state, withdrawal and delayed-retest workflow design.

## Technical stack and methods

Country/language instrument versions; consent/checkpoints; withdrawal; frozen instruments; retest scheduling.

## Evidence inspected

PersonTwin park_collection README and protocol layout. Historical evidence is described; full original experiments were not rerun for this catalog.

## Public material

This card publishes an implementation/research summary. The complete source tree, runtime data and original local evidence are not part of this release.

## Current limits

Protocol code is not evidence of recruited participants, ethics approval or validated translation. Original third-party question tables and restricted instruments are not republished.

## Contribution and upstream scope

Research-protocol adaptation is distinguished from the original Park-related study and external instruments.
