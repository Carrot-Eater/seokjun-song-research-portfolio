# Electronic-nose SDK and experiment tooling

[Area index](../../areas/environmental-sensing/README.md) · [All work](../../ALL_WORK.md) · [Claim boundaries](../../EVIDENCE.md)

**Status:** Software prototype

**Catalog reviewed:** 12 October 2026

Package electronic-nose data handling and experiments into reusable software components.

## Work represented

- SDK modules and reproducible script/test organization.
- Data ingestion and experiment support for multiple sensor-array corpora.
- Interface work spanning host software and firmware-related artifacts.

## Technical stack and methods

Python SDK; sensor schemas; data adapters; scripts; tests; firmware integration scaffolding.

## Evidence inspected

Electronic-nose project enose_sdk, firmware, scripts, tests, pyproject and REPORT. Historical evidence is described; full original experiments were not rerun for this catalog.

## Public material

This card publishes an implementation/research summary. The complete source tree, runtime data and original local evidence are not part of this release.

## Current limits

The existence of software and firmware files does not prove an assembled, calibrated sensor system. This release documents the SDK but does not redistribute its full source.

## Contribution and upstream scope

Original integration scope is separated from public datasets and third-party dependencies.
