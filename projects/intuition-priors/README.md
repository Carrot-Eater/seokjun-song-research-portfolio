# Task-specific intuition priors

직감 사전모형·검증

[Area index](../../areas/persontwin/README.md) · [All work](../../ALL_WORK.md) · [Claim boundaries](../../EVIDENCE.md)

**Status:** Development / evaluation prototype

**Catalog reviewed:** 12 October 2026

Test whether an explicit fast prior improves a later person-specific prediction.

## Work represented

- Task-specific prior construction and development/held-out separation.
- Grounded, prospective and typed-decision experimental branches.
- Explicit feedback records with negative results retained in the research inventory.

## Technical stack and methods

Lexical priors; nested / out-of-fold evaluation; manifests and hashes; held-out prediction records; feedback logs.

## Evidence inspected

PersonTwin intuition_twin README and corresponding prediction research notes. Historical evidence is described; full original experiments were not rerun for this catalog.

## Public material

This card publishes an implementation/research summary. The complete source tree, runtime data and original local evidence are not part of this release.

## Current limits

No validated mental-state inference or autonomous online learning is established. A prior can make results worse; usefulness remains an empirical question.

## Contribution and upstream scope

Project evaluation logic is distinct from the underlying language models.
