Audit whether public sensor data contain enough trustworthy information for transfer and physical interpretation.

## Work represented

- Corpus defects, exposure/air-path reporting gaps and response-curve extraction.
- MOX/PID response lag, temperature/humidity transfer and air-path identifiability investigations.
- Compact olfactory summaries and cross-laboratory response inconsistency.

## Technical stack and methods

Corpus/setup cards; metadata audits; response-curve extraction; time-series analysis; missingness analysis.

## Evidence inspected

gas_data_quality and enose_ml inventories, cross-referenced with the sensing research tree. Historical evidence is described; full original experiments were not rerun for this catalog.

## Public material

This card publishes an implementation/research summary. The complete source tree, runtime data and original local evidence are not part of this release.

## Current limits
