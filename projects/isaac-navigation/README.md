Study high-level navigation and gas exploration using controlled simulation and simple baselines.

## Work represented

- Go2/drone navigation and exploration training/evaluation paths.
- Feed-forward, recurrent and reward variants, including negative results against blind patrol.
- Simulation videos and contract-level checks for selected components.

## Technical stack and methods

Isaac Lab; Python; reinforcement learning; belief/heatmap representations; rollout visualization.

## Evidence inspected

EcoRobotics tools/sim/isaac_rl documentation and rollout artifacts. Historical evidence is described; full original experiments were not rerun for this catalog.

## Public material

This card publishes an implementation/research summary. The complete source tree, runtime data and original local evidence are not part of this release.

## Current limits

Maturity differs between modules. Existing GPU experiments were not rerun for this portfolio; simulated improvement is not hardware transfer.

## Contribution and upstream scope

Uses Isaac Lab and upstream low-level locomotion policies. The work represented is high-level integration and evaluation.
